# Hamid Hussain’s academic website

A responsive Jekyll research portfolio for GitHub Pages. Navigation: Home, Research, Publications, Projects, and CV. Projects are explicitly labeled Project 1, Project 2, and Project 3 placeholders.

## Structure and editing

| Source | Purpose |
| --- | --- |
| `index.md` | Homepage biography and metadata |
| `_layouts/home.html` | Homepage composition |
| `_layouts/default.html` | Document metadata and shared shell |
| `_layouts/project.html` | Shared project detail layout |
| `_data/navigation.yml` | Navigation links |
| `_data/publications.yml` | Confirmed publication entries; currently empty |
| `_includes/header.html`, `_includes/footer.html` | Shared navigation and footer |
| `_includes/project-card.html`, `_includes/project-list.html` | Reusable project cards and listing |
| `_includes/publication.html` | Reusable publication entry |
| `_projects/project-*.md` | Project metadata and Markdown descriptions |
| `research.md`, `publications.md`, `projects.md`, `cv.md` | Academic pages |
| `assets/css/main.scss` | Stylesheet entry point |
| `_sass/_tokens.scss`, `_foundation.scss`, `_components.scss`, `_responsive.scss` | Colors, base styles, shared components, and responsive rules |
| `assets/js/main.js` | Accessible mobile navigation enhancement |
| `assets/images/` | New graphics and project placeholders |

Project cards and detail images use shared styles; update dimensions in one place. Existing `images/`, `tn/images/`, `_posts/`, and `_old_posts/` remain preserved for migration. Legacy template posts are excluded from the build and the global post permalink is `/blog/:year/:month/:day/:title/`, avoiding homepage collisions. Projects use `/projects/:name/`.

## Run locally

Use Ruby 3.1 or newer with Bundler:

```sh
bundle install
bundle exec jekyll serve
```

Production build:

```sh
JEKYLL_ENV=production bundle exec jekyll build --strict_front_matter
```

## Add content

Edit a project’s title, description, image, order, and Markdown body in `_projects/`. Keep `placeholder: true` until the project is ready. Shared project rendering is automatic.

To add a publication, replace the empty list in `_data/publications.yml` with entries containing `title`, `authors`, `venue`, and `year`; optional fields are `url`, `pdf`, and `code`.

A profile photograph and downloadable CV can be added when verified assets are available. Navigation remains visible without JavaScript; on small screens JavaScript adds a keyboard-accessible Menu button.

## GitHub Pages

The redesign preserves the repository’s existing GitHub Pages publishing configuration. If using GitHub’s built-in Jekyll build, publish from the `master` branch and root directory in Settings → Pages. The Gemfile supports local Bundler builds.

`CNAME` is preserved unchanged pending domain verification. Its current content is a URL rather than a custom hostname; verify the intended domain before publishing. For the default `hamidh1.github.io` address, a custom CNAME file is generally unnecessary.

Search metadata is generated by `jekyll-seo-tag` in the shared layout; the sitemap is generated by `jekyll-sitemap`. Both plugins are listed in `_config.yml` and the Gemfile.

## Reference-inspired presentation

The homepage uses a two-column introduction, topic tags, three project cards, and a publication list. Project 1–3 remain placeholders. New PNG robotics imagery is AI-generated and labeled as illustrative. Contact details remain those configured for this site; the reference screenshot’s email and publication claims were not imported. Add `scholar_url` in `_config.yml` to display a verified Google Scholar profile.
